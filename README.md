LNMU Buddy — A Student-Centric Syllabus and Academic Information Platform

Project Repository: https://github.com/tksachin01/LNMUSYLLABUS

1. About the Project

LNMU Buddy is a student-focused digital platform designed to help students access and navigate academic syllabus information associated with Lalit Narayan Mithila University (LNMU).

The project aims to make academic information easier to find, understand, and organize through a simple and accessible interface.

2. Problem Statement

Students may face difficulties locating relevant syllabus documents, identifying course-specific academic information, and navigating information distributed across multiple sources.

LNMU Buddy aims to address this challenge by organizing syllabus-related information in one convenient platform.

3. Proposed Solution

LNMU Buddy provides a centralized interface for accessing available syllabus information and navigating academic content. The project is intended to reduce the effort required to find relevant course information and improve the student experience.

4. Key Features

- Syllabus-focused academic information interface
- Organized subject and course-related content
- Student-friendly navigation
- Web-based application architecture
- Administrative interface for managing supported content
- Scope for future improvements based on student feedback

Feature availability depends on the current implementation and configuration.

5. Technology Stack

- Frontend: React, TypeScript
- Build Tool: Vite
- Backend: Node.js and Express
- Additional Services: Firebase and Google AI integrations, where configured

6. Intended Users

- Students seeking LNMU syllabus information
- Students looking for easier access to academic resources
- Academic communities interested in improving access to educational information

7. Current Status

LNMU Buddy is an ongoing development project. The repository contains the application source code and related project files.

The project requires continued testing, security review, content verification, and usability improvements.

8. Limitations

- Availability of information depends on the content currently included in the application.
- Academic information should be verified against official university sources.
- Features that depend on external services require the relevant configuration.
- A public source-code repository does not itself guarantee a live, publicly accessible application.

10. Installation and Local Development

Prerequisite: Node.js and npm.

1. Clone this repository:
   
   "git clone https://github.com/tksachin01/LNMUSYLLABUS.git"

2. Open the project directory:
   
   "cd LNMUSYLLABUS"

3. Install dependencies:
   
   "npm install"

4. Configure the environment variables required by the application. Keep private API keys and credentials out of Git.

5. Start the development server:
   
   "npm run dev"

Refer to the application configuration and server output for the local address and any additional setup requirements.
